# Vacuum System

Three vacuum regions are described by ZEISS: gun/column, chamber and Dewar. The Vacuum Dashboard displays their pumps, valves, pressures and states.

> **NOTE**  
> User guidance During ordinary operation, use the dashboard for observation. Do not manually run pumps/valves unless acting under an approved Superuser procedure.
