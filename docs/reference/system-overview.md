# System Overview

The ORION NanoFab uses a helium or neon gas field ion source (GFIS). Major subsystems include the GFIS gun/column, process chamber and air lock, ET detector, flood gun, Dewar, gas delivery, vacuum system, operator console, and optional Ga FIB/GIS/NPVE systems.

The ZEISS manual's Figure 4 provides a labeled process-module overview.
