# GFIS Controls

The GFIS column includes the source/extractor, Lens 1, quadrupoles, beam-limiting aperture, blanker/Faraday, octopoles, Lens 2 and column isolation valve. The user interface provides gas, landing energy, aperture, spot, accelerator/lens and alignment controls.
