# Working with Neon

1. Set up the microscope, find your region of interest while working with He. Save stage positions.
2. Stop the scan.
3. In GFIS settings, change aperture to Ne-compatible ones.
4. Select Neon in Gas Control and wait for helium evacuation and neon regulation (~7 min; allow up to ~10 min if the pressure has not stabilized).
5. Proceed with the normal GFIS workflow and re-check alignment. Neon operation uses a lower extractor voltage, set automatically by ZEN when the gas is switched — do not adjust it manually.

> **WARNING**  
> **Aperture warning:** 
> Use the designated neon/moly aperture positions for the installed aperture set.
