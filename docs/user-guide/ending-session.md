# Ending a Session

1. Return tilt and scan rotation to 0°.
2. In GFIS settings, turn off gas. Make sure gas is Off / GFIS is in Standby.
3. Ramp down Lens 2 voltage. When voltage is below 100 V, uncheck the Lens 2 power.
4. Power down the ET detector. Power down flood gun if it was used.
5. When gas evacuation is finished, check the vacuum screen. The Gun to Main Chamber valve should be closed.
6. Select Exchange to move to the transfer position.
7. Unload the sample using Transfer → Store → Vent. Make sure the transfer rod is secured to the sample stage before retraction.
8. After unloading your sample, return the sample stage to the Main Chamber using Store → Transfer → Store.
9. Complete the logbook, clean the work area and transfer data using email.
