# Ending a Session

1. Return tilt and scan rotation to 0°.

1. Select Exchange to move to the transfer condition.

1. Unload the sample using Transfer → Vent → Store, or load the next sample.

1. Make sure gas is Off / GFIS is in Standby.

1. Power down the detector as required; return the standard holder/sample according to the local SOP.

1. Complete the logbook, clean the work area and transfer data using the approved method.
