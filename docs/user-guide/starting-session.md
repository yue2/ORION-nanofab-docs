# Starting a Session

1. Confirm the appropriate aperture before turning on the gun.

1. Power the ET detector; power the flood gun only when needed.

1. Select helium and allow gas pressure to stabilize.

1. Set landing energy, aperture and Spot Control for the intended work.

1. Enable Lens 2 and focus according to the local SOP/training.

> **WARNING**  
> Operator boundary Do not use Extract Voltage as an ordinary user control unless explicitly trained/authorized.
