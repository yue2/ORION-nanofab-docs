# Trimer Check & Alignment

1. Move to the standard Au sample / saved reference site.

1. Rough focus at the documented working distance and use a short dwell time.

1. Enter SFIM mode and grab an image.

1. Check whether the designated trimer atom is centered; use Gun Tilt if adjustment is required.

1. Expose the trimer as briefly as possible, then return to normal imaging/Gun Shift mode.
