# Before You Start

Complete the pre-use checks before beginning a work session.

> **WARNING**  
> No food or drink in the lab!
> Stop conditions Do not proceed if there are unexplained errors, gun temperature is above about 95 K, less than 2 h before LN₂ refill, or vacuum is abnormal. Contact a Superuser.

1. The HIM source is very sensitive to vibration. Cool down body/clothing temperature briefly in the lobby area before entering the lab. Keep your volume low while operating the tool.
2. From the PC, System Manager should be open. Check error messages from the system manager window.
3. Check vacuum screen. If the vacuum screen is not open, find it from the System Manager -> Tools -> Vacuum Screen. Gun vacuum should be ~E-10 torr, Main Chamber should be ~E-8 torr.
4. From the vacuum screen, check gun temperature (normal temperature ~92 K).
5. Check the logbook. Last user's remarks are OK. No irregularities should be mentioned in their remarks. Check the trimer status provided by the last user: follow the trimer atom they used.
6. Open ZEN software. From the top menu bar, select the Dewar Control button to open the Dewar Control window. Check LN₂ remaining time; do not proceed if <2 h.
7. When all checks pass, proceed to load your samples.

Local SOP: Before Measurement.
