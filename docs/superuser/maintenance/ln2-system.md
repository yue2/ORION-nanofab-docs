# LN₂ System

The integrated Dewar cools the GFIS gun to cryogenic temperature and is automatically refilled from an external tank.

1. Before external tank exchange, put Dewar Control into servicing mode / Begin Servicing so Auto Fill cannot start.

1. Standby the GFIS column when moving the tank because movement can disturb the beam.

1. After refill/reconnection, verify valves and use Done Servicing to restore automatic refill.

> **WARNING**  
> Cryogenic hazard Follow institutional LN₂ handling rules and the ZEISS safety labels/MSDS guidance.
