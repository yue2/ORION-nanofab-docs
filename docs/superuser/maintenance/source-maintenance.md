# Source Maintenance

Use the ZEISS source-maintenance sequence as the primary technical reference: process selection, repair/form source, select trimer, determine BIV, align source and set source distance.

> **NOTE**  
> Local maintenance notes supplement this with site-specific observations and recovery steps. Where local and manufacturer procedures differ, resolve the controlled procedure before publication.

## Logic review — incomplete curated procedure

> **WARNING — WAITING FOR MANUAL CONFIRMATION**  
> **ZEISS manual guidance to confirm locally:** Use the GFIS Source Maintenance workflow in this order: Basic Source Maintenance / Process Selection, Form the Source, Select a Trimer, Determine BIV, Align Source, then Set Source Distance. The manual says the default Form the Source selections are **Maintain BIV Source Build** and **Keep most recent field**, and the process should reach **Form Completed / SUCCEEDED** before moving to Select a Trimer. Select a Trimer requires a conductive, preferably featureless sample under the beam.  
> **Manual references:** ZEISS Operator Manual §5.2, printed pp. **95–121** (PDF pages **100–126**); Form the Source §5.2.3, printed pp. **98–104** (PDF **103–109**); Select a Trimer §5.2.4, printed pp. **105–110** (PDF **110–115**).  
> **Waiting for confirmation:** confirm the site-approved process selection, BIV acceptance range, source-alignment acceptance criteria, and source-distance calibration value before this becomes a controlled local workflow.
