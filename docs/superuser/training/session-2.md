# Training Session 2

*Second hands-on session. Prerequisites: Session 1 skills (loading/unloading, focus, alignment) and the Safety Training briefing. The trainee may bring their own sample; it must meet the sample height and mounting rules from Session 1.*

1. **Hands-on repetition of loading/unloading** — supervised repeat of the Session-1 transfer sequence, emphasizing the interlocks and failure modes: never retract the rod before confirming the holder is seated/secure; never force a tilted rod (see [Sample Loading & Unloading](../../user-guide/loading-unloading.md)).
2. **Practice tuning focus on the standard Au sample** — reach rough focus with Lens 2, correct astigmatism, and iterate focus/wobble/gun-shift until the image is stable (see [Starting a Session](../../user-guide/starting-session.md), [Imaging](../../user-guide/imaging.md)).
3. **Practice locating and focusing on the trainee's own sample** — navigate to saved stage positions, find the region of interest, and set focus/contrast/dwell for good imaging.
4. **Flood-gun use on an standard insulating (non-conducting) sample** — before powering the flood gun, confirm the ET detector grid is not shorted (ZEISS §4.9, printed pp. 88–89 / PDF pp. 93–94). Practice line-mode neutralization, flood time, and re-checking astigmatism afterward (see [Imaging — Using flood gun](../../user-guide/imaging.md)).
5. **Patterning using ZEN** — draw a simple shape in the Patterning tab, set dose and verify expected beam current, start/stop the pattern and check the result (see [Patterning — ZEN patterning](../../user-guide/patterning.md)).
6. **Patterning using NPVE** — verify the server/communication connection, grab a reference image, draw or import a pattern, define a stop condition, and run it (see [Patterning — NPVE](../../user-guide/patterning.md); advanced details in the NPVE User Guide).
7. **Review and issue** — review the trainee's training notes and logbook together, answer open questions, and issue the User Guide: point the trainee to the [User Guide section](../../user-guide/starting-session.md) (starting page) and the printable export `exports/user-guide.html`.

*End-of-session check:* trainee can load/unload, focus, use the flood gun on an insulating sample, and run a basic ZEN and NPVE pattern unassisted; formal assessment is tracked in the [Competency Test](../training/competency-test.md).
