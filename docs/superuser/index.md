# Superuser Duties

Restricted tasks performed only by trained Superusers. Normal users should **stop and contact a Superuser** when any of these areas is involved. These pages are access-gated to the Superuser role.

### Training
- **Safety Training** — facility alarms, gas suppression, cryogenic/electrical/chamber hazards.
- **Training Session 1 / Session 2** — hands-on syllabus: transfer, alignment, flood gun, patterning.
- **Competency Test** — pass/fail items required before independent tool access.

### Maintenance
- **Routine Checks** — weekly logs of vacuum, gun temperature, LN₂ and system state, with site normal ranges.
- **LN₂ System** — Dewar auto-fill and external tank handling.
- **Gas Cylinders** — CDA/N₂ pressure monitoring, ordering and cylinder exchange.
- **Trimer Formation** — source formation (source maintenance), trimer selection, BIV and alignment.

### Error & Recovery
- **Planned Shutdown / Power-Up / GFIS Recovery** — controlled shutdown and return-to-service.
- **Troubleshooting** — vent recovery, overheat, vacuum, communication, trimer and image problems.
