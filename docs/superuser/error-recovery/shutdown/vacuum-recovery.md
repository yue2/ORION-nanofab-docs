# Vacuum Recovery

1. Verify Dewar state and required valves.

1. Set GFIS Column to Pump No Ion Pump.

1. Set Chamber to Rough; after Rough Vac, open the Dewar jacket valve as documented.

1. Select Pump for the chamber and monitor transition to Ready.

1. Observe pressure trends before enabling ion pumps or isolation states.

> **WARNING**  
> Do not improvise valve/pump sequencing Use the manufacturer procedure and current site configuration.
