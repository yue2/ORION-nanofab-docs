# Trimer Problems

## Symptom

Use this page when the expected **three-atom trimer cannot be found or formed**, or when source emission is visible but a usable trimer is not available. The local trimer notes explicitly branch to software/hardware communication checks when no trimer is found.

If the trimer cannot be found, local notes first call for checking software/hardware communication, then restarting ZEN/server/PC if necessary. Source maintenance may require a new source build/BIV determination.

> **WARNING**  
> Do not expose the source unnecessarily Use the standard conducting Au sample and minimize SFIM exposure.

## Logic review — incomplete curated procedure

> **WARNING — WAITING FOR MANUAL CONFIRMATION**  
> **ZEISS manual guidance to confirm locally:** when troubleshooting no image, if emission is present but no trimer is available, the manual directs the operator to build/select a trimer using Basic Source Maintenance. The manufacturer workflow separates **Form the Source → Select a Trimer → Determine BIV → Align Source → Set Source Distance** rather than treating connector work as a routine first response.  
> **Manual references:** §7.6.3 Checking for an Ion Beam, printed pp. **172–173** (PDF **177–178**); §5.2 Basic Source Maintenance, printed pp. **95–121** (PDF **100–126**), especially Select a Trimer §5.2.4 printed pp. **105–110**.  
> **Waiting for confirmation:** define the local symptom threshold for software restart versus source rebuild. Physical high-voltage connector cleaning is not established by these Operator Manual sections as a routine trimer-recovery branch and requires separate service/manual confirmation.
