# Troubleshooting

## Symptom

Start here when the instrument shows an abnormal condition, fails to reach an expected state, loses communication, cannot produce a usable trimer/image, or requires an intrusive recovery. Select the page that most closely matches the observed symptom before taking corrective action.

- **Main Chamber Vent Sample holder recovery.**

- **Gun Overheat High-temperature recovery.**

- **Vacuum Problems Dashboard, valves and pumps.**

- **Communication / Firmware Hardware status and Query Nodes.**

- **Trimer Problems Source/trimer checks.**

- **Image Problems Detector, beam and alignment checks.**
